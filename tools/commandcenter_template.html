          How this page stays current

          Status, the game plan, decisions and every release, chat and standing decision from 2.36 on live in this page's own database (2.35 and earlier are built in from the old System Board). Any chat in the Debrief project updates them directly, and the page shows the change within seconds. The code map and components are built from the code at each push with python tools/commandcenter.py, then republished.

          Older hubs (the game plan Whiteboard and the System Board) are history now and are no longer updated.
